# 쿠키런 프로젝트 명세서

## 1. 프로젝트 개요
- 이름: 쿠키런
- 목표: 쿠키런처럼 자동으로 달리는 쿠키 캐릭터가 점프, 이단점프, 슬라이딩으로 장애물을 피하고 젤리와 물약을 모으는 2D 러너 게임
- 최종 형태: 로컬 브라우저에서 실행되는 HTML/CSS/JavaScript Canvas 게임
- 이미지 사용 방식: 외부 캐릭터 이미지를 그대로 쓰지 않고, Canvas 도형으로 직접 그린 쿠키 러너를 사용

## 2. 기술 스택
- 언어: HTML, CSS, JavaScript
- 렌더링: Canvas API
- 실행 환경: Windows 브라우저
- 외부 라이브러리: 없음
- 저장 방식: 브라우저 localStorage에 최고 점수, 보유 코인, 업그레이드 상태 저장

## 3. 핵심 기능
- 캐릭터는 달리기, 점프, 낙하, 슬라이딩 상태에 따라 다른 자세로 표시된다.
- Space 또는 위 방향키로 점프한다.
- 공중에서 한 번 더 점프할 수 있는 이단점프를 지원한다.
- 아래 방향키, Shift, S 키를 누르고 있는 동안 슬라이딩한다.
- 슬라이딩 중에는 캐릭터의 충돌 박스가 낮아져 매달린 장애물을 통과할 수 있다.
- 장애물은 가시, 웨이퍼 벽, 쿠키 블록, 오븐 문, 불기둥, 날아오는 포크, 절벽, 플랫폼 구간, 매달린 슬라이딩 장애물로 구성된다.
- 젤리를 먹으면 이번 코인과 보유 코인이 오른다.
- 보유 코인으로 메인 화면에서 체력, 점프 횟수, 젤리 수익을 강화할 수 있다.
- 게임 중 체력은 시간이 지나며 서서히 감소한다.
- 일정 주기마다 체력 물약이 생성되고, 물약을 먹으면 체력이 회복된다.
- 장애물에 닿으면 즉시 종료되지 않고 체력이 감소한다.
- 절벽에 떨어지면 일반 장애물 충돌보다 큰 체력 피해를 받고 다시 땅 위로 복귀한다.
- 체력이 0이 되면 게임이 종료된다.
- 충돌 직후에는 짧은 무적 시간이 있어 같은 장애물에 연속으로 맞지 않는다.
- P 키로 일시정지, R 키로 재시작한다.

## 4. 사용자 흐름
1. 사용자가 `index.html`을 연다.
2. 메인 화면에서 보유 코인과 업그레이드 상태를 확인한다.
3. 필요하면 체력, 점프 횟수, 젤리 수익을 강화한다.
4. 게임 플레이 버튼 또는 Space 키를 눌러 게임을 시작한다.
5. 쿠키가 자동으로 달리고 장애물이 등장한다.
6. 사용자는 점프, 이단점프, 슬라이딩을 사용해 장애물을 피한다.
7. 젤리를 먹어 코인을 벌고, 물약을 먹어 체력을 회복한다.
8. 충돌, 추락, 시간 경과로 체력이 줄어든다.
9. 체력이 0이 되면 기록 종료 화면이 표시된다.
10. 다시 뛰기 또는 메인 화면 버튼으로 재도전한다.

## 5. 평가 기준
- 조작이 즉시 반응하는가
- 점프와 이단점프가 명확하게 구분되는가
- 슬라이딩 장애물이 서 있으면 맞고, 슬라이딩하면 피할 수 있는가
- 각 장애물의 시각적 구분이 쉬운가
- 젤리 코인이 정상적으로 쌓이는가
- 업그레이드가 보유 코인을 소모하고 실제 능력치에 반영되는가
- 체력이 시간 경과에 따라 줄고 물약으로 회복되는가
- 체력 감소와 게임 종료가 정상적으로 작동하는가
- 충돌 판정이 캐릭터 그림과 크게 어긋나지 않는가
- 이미지 노동 없이도 게임 목적과 캐릭터가 잘 전달되는가

# 쿠키런 테스트 체크리스트

- [ ] `index.html`을 열면 메인 화면과 업그레이드 목록이 보인다.
- [ ] 보유 코인이 메인 화면과 상단 HUD에 같은 값으로 표시된다.
- [ ] 게임 플레이 버튼을 누르면 게임이 시작된다.
- [ ] Space 또는 위 방향키를 누르면 쿠키가 점프한다.
- [ ] 공중에서 한 번 더 누르면 이단점프가 된다.
- [ ] 점프 횟수 업그레이드 전에는 세 번째 점프가 되지 않는다.
- [ ] 점프 횟수 업그레이드 후 최대 점프 횟수가 늘어난다.
- [ ] 아래 방향키, Shift, S 키를 누르고 있으면 쿠키가 슬라이딩한다.
- [ ] 슬라이딩을 놓으면 달리기 자세로 돌아온다.
- [ ] 매달린 장애물과 날아오는 장애물은 서 있으면 충돌한다.
- [ ] 매달린 장애물과 날아오는 장애물은 슬라이딩하면 통과한다.
- [ ] 젤리를 먹으면 이번 코인과 보유 코인이 오른다.
- [ ] 젤리 수익 업그레이드 후 젤리 1개당 코인 획득량이 늘어난다.
- [ ] 체력이 달리는 동안 서서히 줄어든다.
- [ ] 체력 물약을 먹으면 체력이 회복된다.
- [ ] 체력 업그레이드 후 시작 체력과 물약 회복량이 증가한다.
- [ ] 가시에 닿으면 체력이 줄어든다.
- [ ] 벽, 쿠키 블록, 불기둥에 닿으면 체력이 줄어든다.
- [ ] 절벽에 떨어지면 일반 벽 충돌보다 2배 이상 큰 피해를 받는다.
- [ ] 충돌 직후 짧은 무적 시간이 적용된다.
- [ ] 높은 벽과 플랫폼 구간은 이단점프 또는 플랫폼 착지가 필요하다.
- [ ] 공중 플랫폼 위에 착지할 수 있다.
- [ ] 플랫폼에서 떨어지면 다시 낙하한다.
- [ ] 거리가 증가할수록 속도가 조금씩 빨라진다.
- [ ] 체력이 0이 되면 게임 오버가 된다.
- [ ] 게임 오버 화면에서 다시 뛰기와 메인 화면 이동이 가능하다.
- [ ] P 키로 일시정지와 계속하기가 가능하다.
- [ ] R 키로 재시작할 수 있다.
- [ ] 최고 점수와 업그레이드 상태가 새로고침 뒤에도 유지된다.
- [ ] 쿠키의 달리기, 점프, 슬라이딩 자세가 서로 다르게 보인다.
- [ ] 캐릭터 그림과 충돌 박스가 크게 어긋나지 않는다.
